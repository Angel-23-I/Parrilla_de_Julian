PARRILLA DE JULIAN - Proyecto web academico
=========================================

Nombre del proyecto:
Parrilla de Julian

Tecnologias utilizadas:
- HTML5
- CSS3 (css/estilos.css)
- Bootstrap 5.3 mediante CDN
- Bootstrap Icons mediante CDN
- Google Fonts (Oswald + Lora) mediante CDN
- Sin JavaScript propio. Solo el JS de Bootstrap para el navbar responsive.

Estructura de carpetas:
parrilla-de-julian/
├── index.html
├── menu.html
├── promociones.html
├── nosotros.html
├── contacto.html
├── css/
│   └── estilos.css
├── img/
└── README.txt

Como ejecutar el proyecto:
1. No requiere instalacion ni servidor.
2. Abrir index.html en el navegador (doble clic).
3. Navegar con el menu superior a Menu, Promociones, Nosotros y Contacto.
4. Se requiere conexion a internet para que Bootstrap, Bootstrap Icons
   y Google Fonts se carguen mediante CDN.
